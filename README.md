# Google Play Account Deletion Portal

This repository contains the source code for the **Account Deletion Request** portal, which provides specific instructions for users to delete their accounts and associated data for applications published by **FoxCraftCandide** on Google Play.

## 🚀 Overview

To comply with Google Play's data safety requirements, this portal serves as a centralized hub where users can find detailed, app-specific instructions on how to request the deletion of their personal data.

### Supported Applications

All applications developped by FEA

## 📁 Project Structure

- `index.html`: The main landing page for selecting an application.
- `pages/`: Contains specific deletion instructions for each application.
- `static/`: Assets including CSS, JavaScript, and icons.
  - `style.css`: Modern, responsive styling with glassmorphism effects.
  - `script.js`: Logic for navigation and form handling.
  - `icon.png`: Project favicon and apple-touch-icon.

## 🛠️ Built With

- **HTML5**: Semantic structure.
- **Vanilla CSS**: Custom styling with gradients and animations.
- **JavaScript**: Client-side interactivity.
